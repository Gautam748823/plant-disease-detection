# plant-disease-detection

Project Problem Statement

Agricultural productivity is significantly affected by plant diseases, which often go undetected until they cause serious damage. Farmers traditionally rely on manual observation to identify diseases, a process that is time-consuming, inaccurate, and dependent on expert knowledge. This leads to delayed treatment, reduced crop yield, and excessive use of pesticides, which harms the environment and increases costs. With the growing demand for sustainable and smart farming, there is a need for an automated, intelligent system that can accurately detect plant diseases at an early stage using image-based analysis.

Project Problem Statement

To address this issue, there is a need for an intelligent, automated system that can accurately classify plant diseases using advanced technologies like Convolutional Neural Networks (CNNs). Such a system can help farmers take timely preventive actions, reduce chemical usage, improve crop health and yield, and support sustainable agriculture practices.

DataSet

• Dataset Name: PlantVillage Dataset

A Comprehensive Image Dataset for Plant Disease Classification and Agricultural Health Monitoring

About Dataset

This dataset contains images of plant leaves categorized into 38 classes, designed for machine learning and computer vision projects focusing on plant disease detection and precision agriculture. It includes healthy and diseased leaf images across 14 different plant species including Tomato, Potato, Apple, Grape, Corn, and more. It is ideal for building classification models or developing AI-powered solutions for sustainable farming and early disease intervention.
