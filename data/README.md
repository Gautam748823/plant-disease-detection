# Dataset Folder

This folder contains the PlantVillage dataset used for training.

## Download Dataset

Due to GitHub file size limits, download the dataset from:
- [PlantVillage Dataset on Kaggle](https://www.kaggle.com/datasets/emmarex/plantdisease)

## Structure
```
data/
├── PlantVillage_Dataset/
│   ├── Tomato___Bacterial_spot/
│   ├── Tomato___Early_blight/
│   └── ... (15 classes total)
```

Place the downloaded dataset here before training.


## Instructions

1. Download the dataset from the Kaggle link above.  
2. Extract it and place the **PlantVillage_Dataset** folder inside this **data/** directory.  
3. Your structure should look like this:

plant-disease-detection/
├── data/
│ └── PlantVillage_Dataset/
│ ├── Tomato___Bacterial_spot/
│ ├── Tomato___Early_blight/
│ └── ... (15 classes)

4. Then you can start training your model.
